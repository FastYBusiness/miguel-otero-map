## ¿Qué es esto?

No es un CV tradicional. Es una **aplicación interactiva de exploración de capacidades operativas** que responde a tres preguntas fundamentales:

Este proyecto refleja un principio fundamental:

> **Las capacidades no son lo que aprendes, sino lo que logras en contextos reales.**

No busca impresionar con un CV bonito. Busca demostrar:

1. **Coherencia:** Entre capacidades declaradas y evidencias
2. **Integración:** De múltiples dimensiones (operaciones, liderazgo, personas, tecnología)
3. **Continuidad:** 35+ años de aprendizaje y adaptación
4. **Responsabilidad:** Documentación verificable de cada afirmación

## 📝 Interpretación del Árbol

El árbol NO es cronológico. Es **jerárquico por relevancia**:

```
Nivel 1: Propuesta de Valor (¿Qué prometo?)
Nivel 2: Capacidades Core (¿Cómo lo hago?)
Nivel 3: Especialidades (¿En qué me especializo?)
Nivel 4: Evidencias (¿Cómo lo pruebo?)
Nivel 5: Experiencia (¿Dónde lo hice?)
```

La **cronología está en Experiencia** (rama 5), no al inicio. Porque lo importante no es dónde trabajaste, sino qué capacidades desarrollaste.
